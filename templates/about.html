About the project

IoT networks connect billions of home, industrial and infrastructure devices. Many are resource-constrained and lightly secured, which makes them easy to enrol in botnets controlled by a command-and-control (C&C) server for DDoS attacks, data theft and network disruption.

Why existing systems fall short
  • Signature-based IDS (e.g. Snort, Suricata) miss new or polymorphic botnet variants.
  • Rule-based anomaly detection is static, needs manual updates and struggles with IoT diversity.
  • High false positives/negatives, scalability limits and little temporal analysis (e.g. periodic C&C beacons).
What this system adds
  • Machine-learning classification of network flows into Benign or Malicious.
  • Models that can be retrained on new data to follow evolving threats.
  • A web interface to upload data, compare algorithms, score flows and read mitigation advice.

System modules

  1. Authentication – registration and login (MySQL)
  2. File management – CSV upload and storage
  3. Data processing – imputation, label encoding, train/test split, k-fold
  4. Model selection – compare pre-tested algorithms
  5. Prediction – single-flow scoring from 17 numeric inputs
  6. Presentation – Bootstrap templates and styled tables
